# Carpeta de entregas

Cada integrante tiene su propia carpeta, identificada por su número (P01 a P23).

**Sube tu archivo solo a la carpeta de tu número.** Nadie escribe en la carpeta de otro:
así es imposible que alguien borre tu trabajo, y que tú borres el de otro.

GitHub deja registrado quién subió cada archivo y a qué hora. Ese registro es la
evidencia de participación individual que revisa el profesor.
